# 氧氣與二氧化碳性質比較

*   Ca(OH)₂ (aq) + CO₂ (g) → CaCO₃ (s) + H₂O (l) 可能會生成白色沉澱物。

| 性質 | 氧 | 二氧化碳 |
| :--- | :--- | :--- |
| 它是甚麼顏色的？ | 無色 | 無色 |
| 它有甚麼氣味？ | 無味 | 無味 |
| 燃燒中的木條有甚麼變化？<br>(燃燒加劇 / 火焰熄滅) | 燃燒加劇 | 火焰熄滅 |
| 有餘燼的木條有甚麼變化？<br>(重燃 / 餘燼熄滅) | 重燃 | 餘燼熄滅 |
| 碳酸氫鹽指示劑有甚麼變化？<br>(寫出顏色的變化) | 沒有顏色變化 | 變為黃色 |
| 石灰水有甚麼變化？<br>(寫出顏色的變化) | 沒有顏色變化 | 變為乳濁 |
